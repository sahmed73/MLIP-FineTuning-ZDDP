# DFT reference dataset: round-0 fine-tuning split

These extended XYZ files contain **651 reference configurations**: 404 training, 90 validation and 157 test. OMol25 replay data are not included. ASE can read them with `ase.io.read`. Each configuration has positions in Å, `REF_energy` in eV (total electronic energy), and `REF_forces` in eV/Å (negative energy gradients). Metadata include `calc_id`, `config_type`, total `charge`, `spin` (multiplicity, 2S+1), `group` and `split`. `splits.csv` records the grouping and sizes; check file integrity with `sha256sum -c SHA256SUMS` from this directory.

## How the labels were produced

1. **Sample structures.** Assemble molecular conformers, finite-temperature snapshots, intermolecular pairs and clusters, reaction-related geometries and targeted ZDDP bond-stretch configurations. Bond-stretch sets include scan configurations and frames sampled near selected points. These structures cover the targeted study, not all possible ZDDP chemistry.
2. **Calculate DFT energies and gradients.** Run ORCA 6.1.1 single-point calculations with ωB97M-V/def2-TZVPD and OMol25-style settings: EnGrad, RIJCOSX, def2/J, DEFGRID3, tight SCF convergence, no symmetry and a custom def2-TZVPD basis. OMol25 used ORCA 6.0.0. Specify charge and spin multiplicity. Higher multiplicities use unrestricted Kohn–Sham; singlets containing Zn or marked bond-breaking use unrestricted calculations with a 20° HOMO–LUMO rotation; other singlets use restricted Kohn–Sham. Some stretched-bond singlets also use broken-symmetry starts; the workflow selects the lower solution where specified.
3. **Check and collect.** Accept labels only after normal termination, converged SCF, a complete gradient, coordinates matching the input and consistent output and gradient-file energies. Forces are negative gradients. The round-0 workflow excludes higher-energy duplicate or superseded singlet solutions and rigid clashing association configurations. Seven finite-temperature labels were changed to lower singlet solutions before the refit.
4. **Split without scan-point leakage.** Assign structures by group. For round-0 bond scans, singlet, triplet and nearby thermal frames associated with a scan point remain together. The split does not hold out entire bond types. Other grouping rules vary by source family; see `splits.csv`. Do not train on the test set when reproducing the reported metrics.

## Interpretation and limitations

Energy is the original total DFT energy; **no atomic-reference subtraction** is applied in these files. Absolute energies for different compositions need appropriate references before comparison. Force components, not force magnitudes, underlie the parity metrics. The released DFT data were extracted from the saved fine-tuned prediction archive's reference fields for the exact split IDs; model predictions were removed. They reproduce the recorded split, not all calculated labels or later active-learning rounds. Full ORCA inputs and outputs, model checkpoints and OMol25 replay data are not included. The dataset does not replace out-of-distribution testing or experimental validation.
